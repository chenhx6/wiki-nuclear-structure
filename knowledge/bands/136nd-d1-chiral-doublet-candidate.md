# `136Nd` D1/D1-C Candidate

## Stable Identity

Linked positive-parity D1/D1-C is one of the four weak candidate pairs in Petrache 2018.

## Level and Transition Data

D1/D1-C relative populations are about `1.73%/0.22%`. Energy/alignment comparison supports pairing, but experimental ratios are not available for both members.

## Spin-Parity Evidence

Assignments use the combined multipolarity/polarization program whose detailed audit is deferred.

## Configuration Assignment

Configuration A (`β=0.21, γ=21°`) reproduces D1. D1-C is assigned the same intrinsic state because no other tested configuration reproduces it, an inference bounded by model-space completeness.

## Proposed Interpretation

The authors call D1/D1-C good chiral candidates, not the one clear pair.

## Discriminating Observables

Partner-resolved `B(M1)/B(E2)`, absolute strengths and a D1-specific 3D calculation.

## Competing Interpretations

Untested configurations or mixing could change the shared-intrinsic assignment; calculated absolute D1 ratios underestimate experiment.
