# 131Ce

## Identity

Z=58、N=73 的奇中子核。本页以 Alwaleedi 2013 的 Bands 1–7 为当前高自旋结构基线；来源编号不自动与其它论文编号合并。

## Production Reactions

- 165 MeV 100Mo(36S,5nγ)131Ce，ATLAS/Gammasphere：[[atlas-gammasphere-131ce-s36-165mev]]。

## Established Level Structure

Alwaleedi 2013 报告两条新的强耦合带 Bands 4、7，并扩展 Bands 1、2、6；Figure 4.1 与 Tables 4.1–4.7 是本 Wiki 当前采用的能级纲图基线。自旋宇称依赖 coincidence、angular intensity ratio 与来源中的组态论证，确定度并非逐态相同。

## Bands

- 本轮 claim-level working parity：Bands 2、3、5 为正宇称，Bands 1、4、6、7 为负宇称。该判断由用户依据 Figure 4.1 提出，并已与 Tables 4.1–4.7 和 Chapter 5 交叉核验；状态仍为 provisional。
- Band 1/4：负宇称强耦合序列及其 γ-coupled 候选关系；
- Band 2：正宇称低-j 中子轨道序列；Band 7 的负宇称 working assignment 与 Table 5.3 的 `a/b⊗AE` 组态相容；
- Bands 3、5、6：由 alignment、crossing 和 Table 5.3 组态图约束。

Table 5.1 将 Band 2 标为负宇称，与 Figure 4.1、Tables 4.5–4.6 和正宇称带讨论冲突，当前视为 probable typo；保留原表冲突，不用该单元覆盖 working parity。

当前不为 Bands 1–7 机械建独立页；只有跨来源 identity 稳定并承担多个重要 claim 时再拆分。

## Deformation and Collective Features

- Woods–Saxon/TRS 背景给出 β2=0.218、β4=-0.023、γ=0°，属于模型结果。
- 作者用 spin-dependent core polarization 和可能的高自旋非轴形变解释部分 crossing 后行为。
- 当前没有直接 γ-rigidity、寿命或绝对 E2 证据，不能把该核归类为已确立 wobbling、chirality 或 shape coexistence。

## Competing Interpretations

首要基线是 signature/configuration coupling 与准粒子 crossings；γ-soft 粒子—芯耦合可作为后续统一解释候选。wobbling、chirality 和 shape coexistence 需要额外的带间电磁跃迁、寿命、偏振或形变敏感证据。

## Key Observables

- angular intensity ratios 与跃迁多极性；
- crossing frequencies、alignment gains 和 signature splitting；
- 在 δ=0 假设下推导的 B(M1)/B(E2)；`R(δ)=R(0)/(1+δ²)`，`|δ|≤0.5` 时 δ=0 结果相对真实值最多高估 25%（相对 `R(0)` 的差值最多 20%）；
- 尚缺：mixing ratios、线偏振、寿命/绝对 B(E2)、transition quadrupole moments 和直接形变敏感量。

## Open Questions
