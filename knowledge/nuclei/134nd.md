# `134Nd`

## Identity

`Z=60`、`N=74` 的 even-even nucleus。当前页面分层保存 Klemme 1999 的 normal-deformed g.s.b./γ/S1/S2 precision lifetimes 与 Petrache 1998 的 high-spin/highly-deformed DSAM `Q0`；两套结构不能按同核素直接合并。

## Production Reactions

- 132 MeV `110Pd(28Si,4n)134Nd`，GASP+ISIS thick-target DSAM：[[lnl-gasp-isis-pd110-si28-132mev]]。
- 125 MeV `110Pd(28Si,4n)134Nd`，GASP-II coincidence plunger/DDCM：[[lnl-gasp-ii-plunger-pd110-si28-125mev]]。

## Established Level Structure

Klemme 1999 测得 g.s.b., γ, S1/S2 与 negative-parity states 的 12 个 lifetimes，并由 branching 提取 `B(E2)/Q_t`。Petrache 1998 同时分析 yrast HD、excited HD 与 Band 3；该文不重建完整 level scheme，而以已知 in-band transitions 做 centroid-shift analysis。

## Bands

- normal g.s.b.：`2+,4+,6+,8+` 的 `Q_t=4.32(7),4.40(5),3.98(+0.16/-0.08),3.70(19) eb`；前两点平均 `Q0=4.37(4) eb`, `β2=0.246(2)`。
- S1：crossing `ℏω≈345 keV` 后 `Q_t` 从 `4.65(+0.21/-0.14)` 升到 `5.5(3) eb`。
- S2：crossing `ℏω≈462 keV`；`10+,12+,16+` 为 `2.16(12),3.76(13),3.8(+0.4/-0.3) eb`，显著低于 S1；neutron/proton `(h11/2)^2` alternatives 未裁决。
- γ band：`8γ+→6γ+` 的 `B(E2)=0.77(+0.34/-0.20) e²b²`；对 O(6) 偏大，rigid-triaxial rotor 可复现该值但不能统一复现其它 observables。
- yrast HD：`Q0=6.8(3) eb`、`Q_sf=6(1) eb`、axial mapping `β2=0.35(1)`；作者引用 one-`νi13/2` assignment。
- excited HD：`Q0=6.4(4) eb`、`Q_sf=6(1) eb`、`β2=0.33(2)`；作者引用 crossing 前 one、后 two `νi13/2` assignment。
- Band 3：crossing near `I≈30ℏ`；lower `Q0=4.9(3) eb`，upper `~6.5 eb` 但误差约 20-30%；单一全带 `Q0=5.0(3) eb` 也不能由当前统计 firm 排除。

当前不创建独立 band pages：normal/HD band 的稳定 configuration 与跨来源 identity 仍需回到各自早期 level-scheme sources。

## Deformation and Collective Features

三条带的相对 `Q0` 不随建议 `νi13/2` occupancy 显示简单单调增长。作者用 intruder shape polarization 与 rotation-induced shrinking 的竞争解释；该解释来自 paired cranked-Strutinsky calculations。Table I 的 `β2` 明确假设无三轴性。

Normal-deformed low-spin `Q_t` 可由 axial-rotor average 表示，但 energy ratios/staggering 与 O(6)/TRS comparisons 支持 γ-soft background；Klemme 1999 强调无单一 collective model 能整体复现实验。TRS 的 high-frequency `β≥0.3` second minimum 是 S1 strong collectivity 的模型候选。

## Competing Interpretations

Band 3 可采用 crossing 前后不同 `Q0`，也可用全带常数 `Q0` 拟合；当前统计不能 firm 区分。Predicted spin-dependent shrinkage 与 fractional-shift data 大体相容，但 individual transition lifetimes 未解析，不能写成直接观察到随自旋收缩。

Klemme 1999 的 S1/S2 `Q_t` 差异支持 band-dependent shape change，但 `[541]1/2`、neutron/proton `(h11/2)^2` assignments 与 γ/S-band mixing mechanism 均未唯一裁决。γ-softness、rigid triaxiality 与 level mixing 对部分 observables 可给相近解释。

## Key Observables

- angle-dependent peak centroids 与 fractional Doppler shifts `F(τ)`；
- in-band `Q0` 与 side-feeding `Q_sf`；
- axial `Q0→β2` mapping；
- calculated spin-dependent charge quadrupole moments。
- coincidence-RDDS lifetimes、branching-derived `B(E2)/Q_t`、DDCM `τ(x)` consistency；
- g.s.b./γ/S1/S2 crossing-dependent collectivity。

## Open Questions

- 更高统计的 transition-by-transition lifetime 能否区分 Band 3 单一与 crossing-dependent `Q0`？
- 早期 level-scheme sources 对 yrast/excited HD/Band 3 的 configuration assignment 有多强的独立实验约束？
- 后续关于 `134Nd` 的 chirality 或 triaxial-band 讨论是否涉及同一结构，还是不同 spin/configuration sector？
- S1/S2 microscopic configurations 与 γ-band interaction 能否由 polarization、g factor 或更完整 absolute interband strengths 裁决？
