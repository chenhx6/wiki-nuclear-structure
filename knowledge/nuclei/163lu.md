# `163Lu`

## Identity

`A=163`、`Z=71`、`N=92` 的奇 A 镥核。它不属于 A≈130 质量区；本页在当前 Wiki 中用作三轴超形变与高自旋转动判据的非 A≈130 参照案例。

## Production Reactions

[[domscheit-1999-triaxial-superdeformation-163lu]] 使用 145 MeV `29Si` 轰击薄自支撑 `139La` 靶，论文将反应统写为 `139La(29Si,xn)`。形成 `168Lu` 复合核后，`139La(29Si,5n)163Lu` 产生本文核素，4n 道产生 `164Lu`；本文不讨论后者的能级与带结构。

[[odegard-2001-evidence-wobbling-163lu]] 使用 Strasbourg Euroball IV 的 `139La(29Si,5n)163Lu`、152 MeV 数据，建立九条 TSD2→TSD1 连接跃迁并进行 DCO、角分布和偏振分析。

[[jensen-2002-second-phonon-wobbling-163lu]] 使用同一反应的 157 MeV 高统计 Euroball IV 数据，建立 TSD3→TSD2/TSD1 衰变路径并检验 two-phonon strength scaling。

## Established Level Structure

1999 工作把 [[163lu-sd1]] 与正常形变结构连接，确定 SD1 带头为 `13/2+`，并在 Fig.2 给出延伸到 `77/2+` 的序列。2001 工作进一步把 TSD1 延伸约 `10ħ`，同时把 TSD2 向低、高自旋分别延伸约 `6ħ` 和 `4ħ`。正常形变侧包含作者指认为 `[411]1/2+`、`[404]7/2+` 和 `[523]7/2-` 的带结构。

## Bands

- [[163lu-sd1]]：已连接到正常形变态，带头 `13/2+`；
- [[163lu-sd2]]：较弱的第二条 TSD 带；1999 工作未建立连接，2001 工作建立九条到 TSD1 的连接跃迁并由作者指认为 `n_w=1` wobbling；
- [[163lu-tsd3]]：连接到 TSD2 和 TSD1 的第三条 TSD 序列；作者依据一个关键 476-keV link 的大-E2 branch 指认为 `n_w=2`。
- 正常形变 `[411]1/2+`、`[404]7/2+`、`[523]7/2-` 带本轮不单独建页。

## Deformation and Collective Features

SD1 早先寿命结果给出 `Q_SD=10.7(7) b`；1999 文献的两带混合分析给出 `Q_ND/Q_SD=0.48(7)`，并显示 SD1、SD2 有相近转动惯量。UC/PES 在大形变处给出 `γ≈+20.6°` 和 `-15.0°` 极小值；这些 γ 值是模型结果，不是直接实验测量。

## Competing Interpretations

1999 来源中 SD2 仍可解释为不同 `(π,α)` 的三轴 SD 组态或 wobbling 候选。2001 来源通过九条连接跃迁、以 E2 为主的 `δ` 分支和相对强度比较，拒绝其所检验的 signature-partner/three-quasiparticle alternatives，并由作者指认为 `n_w=1` wobbling。该结论依赖相对强度与示意性粒子-转子模型，Wiki 保留其来源尺度和后续比较空间。

## Key Observables

- SD1/SD2 的 `J^(1)` 与 `J^(2)`；
- SD1 的带内和 SD-ND linking γ 跃迁及 DCO；
- 两带混合参数与带外/带内分支；
- Ref.[2] 寿命测量给出的 SD/ND 四极矩。

## Open Questions

- SD2 的确定激发能、自旋宇称和 SD1-SD2 linking transitions 是什么？
- linking transitions 的 M1/E2 多极性及绝对强度是否支持 wobbling？
- 独立观测能否区分正、负 γ 极小值及 γ-soft/γ-rigid 动力学？
